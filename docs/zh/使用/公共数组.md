# 公共数组

公共数组是模块之间的共享数据通道：公开者把数组对象映射到名字，其他模块按名字或模式拉取同一对象引用。

## 三段式命名

完整名 = public:模块名:数组名：

- 第一段 public：公共数组标记，固定
- 第二段：拥有者模块名，核心自动拼装
- 第三段：模块公开时给数组起的名字

公开与取消时模块只提供第三段。

## 公开

```js
ctx.exposeArray('marks', ['ready']);
// 完整名 = public:greeter:marks
```

规则：

- 存引用不拷贝，修改对所有持有者即时可见
- 完整名全局唯一，重复公开报错
- 内容必须是数组

## 拉取

```js
// 精确：完整名，返回数组引用
const marks = ctx.array('public:greeter:marks');

// 精确：自己的数组用第三段短名（自动补齐前两段）
const own = ctx.array('marks');

// 通配：返回 { 数组全名: 引用 } 映射
const all = ctx.array('public:greeter:*');
```

拉取不存在的数组（精确模式）抛错。

## 取消公开

```js
ctx.unexposeArray('marks');
```

仅拥有者可执行。

## 生命周期

- 模块停止或核心停机：其全部公开数组自动注销
- 持有旧引用的代码仍可操作原数组对象，但按名字已不可见
- 数组无容量限制、无持久化，内容管理是模块的职责
- 数组操作不记日志
