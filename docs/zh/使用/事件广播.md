# 事件广播

事件是模块之间协作的主通道：一处发出，多处响应。

## 事件对象

事件由两个字段组成：

- name：完整事件名，两段式 来源:事件名
- data：事件内容，可选，发出方自己写

## 事件名两段式

来源段由核心自动拼装：

- 模块发出：模块名
- 核心自产：core
- 宿主直接调用：external

模块只写事件名段（sendEvent 的第一个参数），无法伪造来源段。

## 发送

```js
ctx.sendEvent('greet', { name: 'world' });
```

事件即发即弃：不排队、不重试。

## 接收声明

模块在 YAML 中声明接收：

- startEvents：事件出现时核心启动模块（启动信号）
- listen：事件出现时核心向模块转发事件（工作指令）

同一事件对未运行模块是启动信号，对运行模块是工作指令。

## 通配符

模式支持 *（任意字符序列）与 ?（单个字符）。响应任意来源的同名事件：

```yaml
listen:
  - "*:greet"
```

## 接收

```js
onEvent(ctx, event) {
  // event.name = 完整事件名，event.data = 内容
  ctx.log('收到', event.name);
}
```

监听者按加载顺序逐个收到事件；单个模块处理失败不影响其他模块。每个监听者收到的是 data 的独立副本（深拷贝）：修改自己的副本不影响其他监听者。data 只承载信息，可变共享数据用公共对象。

## 事件丢弃

无人监听的事件记 event-drop 日志。
