# 日志与命令行

## 日志

日志只记录核心的动作，是连续的时间线。每条日志三字段：

- type：日志类型
- source：动作涉及的对象（core、模块名、external）
- message：具体内容

附加结构化字段按类型出现：event（事件名）、data、recipients（转发名单）、reason、error、file、removedObjects、command。

### 类型全集（15 种）

按类别划分：

- 核心启停：core-start、core-stop
- 事件处理：event、event-drop
- 模块生命周期：module-start、module-stop、module-skip、module-start-timeout、module-restart
- 配置热加载：config-load、config-update、config-remove
- 模块日志：module-log
- CLI 指令：cli-command
- 错误：error

### 存储与轮转

- JSONL 落盘，内容完整
- 按天分文件，单文件超过 128KB 启用新文件
- 进程重启后沿用当天文件
- 内存保留最近 20000 条供进程内查询
- 展示层超长内容截断并标注原始长度，落盘不动

### 模块日志

```js
ctx.log('开始制冷', room);
```

## 命令行

modules/cli 目录中的 cli 模块提供终端界面。指令经定向通道发送，结果经 onMessage 回传。

| 指令 | 参数 | 说明 |
| --- | --- | --- |
| event | name, data | 产生一个事件 |
| start | module | 启动模块 |
| stop | module | 停止模块 |
| send | name, targets | 定向发送事件；* 广播，逗号分隔多目标，目标无需声明监听 |
| state | 无 | 查询模块与公共对象 |
| exit | 无 | 先把结果交付发起方，再关闭核心 |

本地指令（cli 模块自身处理）：

- log [过滤词] [条数]：查看日志时间线
- help：显示帮助
- print：输出测试文本
