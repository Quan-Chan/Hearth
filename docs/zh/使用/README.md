# 使用文档

本文档描述 Connect-Core 提供给模块编写者与宿主集成者的全部功能。

## 模块是什么

模块是 YAML 配置与程序文件的组合：

- YAML 声明模块名、程序文件路径、启动事件、监听事件
- 程序文件导出对象，含四个可选钩子

模块文件夹被核心持续监听，YAML 新增、修改、删除即时生效，无需重启。

## 三条通道

- 事件广播：一个事件名加可选数据，发给所有声明接收的模块
- 定向信息：指定一个目标发送内容，目标经核心校验
- 共享数组：把数组对象映射到名字，其他模块按名字或模式拉取

## 两套命名规范

事件名两段式：来源:事件名。来源段由核心自动拼装（模块发出为模块名，核心自产为 core，宿主调用为 external），模块只写事件名段。匹配使用完整事件名；响应任意来源的同名事件用通配符，如 *:greet。

数组名三段式：public:模块名:数组名。公开与取消时模块只提供第三段（数组名），前两段自动拼装。

## 快速上手

一个模块由两个文件组成：YAML 声明 name、file、startEvents、listen；程序文件导出四个可选钩子。完整示例见模块配置、模块程序、事件广播各篇。核心启动时发出 core:startup，声明监听该事件的模块自动启动。
