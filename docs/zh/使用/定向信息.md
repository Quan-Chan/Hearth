# 定向信息

定向信息是点对点通道：指定一个目标发送内容，中间经过核心。与事件的区别：没有事件名、不参与匹配、不进公共数组。

## 发送

```js
const ok = await ctx.sendTo('worker', { task: 'build' });
```

返回是否送达：

- true：目标存在、在运行、实现了 onMessage，消息已投递
- false：目标不存在、未运行或未实现 onMessage

送达不代表处理成功：对方处理抛错时也返回 true，错误只进日志。

## 接收

```js
onMessage(ctx, message) {
  // message.source = 发送者模块名
  // message.data = 内容
}
```

显式订阅：不实现 onMessage 的模块收不到任何定向信息。

## 请求-应答

应答方用 sendTo 直接回复发起方：

```js
onMessage(ctx, message) {
  ctx.sendTo(message.source, { result: 'done' });
}
```

多个请求方互不串扰。

## 核心寻址

目标为 core 时，核心把信息解释为管理指令并执行，结果直接回传发起方：

```js
ctx.sendTo('core', { cmd: 'state' });
```

指令与参数见日志与命令行文档。
