# 公共对象

公共对象是模块之间的共享数据通道：公开者把对象映射到名字，其他模块按名字或模式拉取同一对象引用。

## 三段式命名

完整名 = public:模块名:对象名：

- 第一段 public：公共对象标记，固定
- 第二段：拥有者模块名，核心自动拼装
- 第三段：模块公开时给对象起的名字

公开与取消时模块只提供第三段。对象名（第三段）不能含冒号（:），冒号是名字分隔符。

## 公开

```js
ctx.exposeObject('marks', { items: ['ready'] });
// 完整名 = public:greeter:marks
```

规则：

- 存引用不拷贝，修改对所有持有者即时可见
- 完整名全局唯一，重复公开报错
- 取值必须是非 null 的对象；对象里放数组、嵌套对象、计数器都可以

## 拉取

```js
// 精确：完整名，返回对象引用
const marks = ctx.object('public:greeter:marks');

// 精确：自己的对象用第三段短名（自动补齐前两段）
const own = ctx.object('marks');

// 通配：返回 { 对象全名: 引用 } 映射，键按自然排序（与模块加载顺序同规则）
const all = ctx.object('public:greeter:*');
```

拉取不存在的对象（精确模式）抛错。

## 取消公开

```js
ctx.unexposeObject('marks');
```

仅拥有者可执行。

## 生命周期

- 模块停止或核心停机：其全部公开对象自动注销
- 持有旧引用的代码仍可操作原对象，但按名字已不可见
- 对象无容量限制、无持久化，内容管理是模块的职责
- 对象操作不记日志
- 核心停机期间拒绝新的公开：exposeObject 抛 Hearth is stopping, cannot expose shared object
- 在 stop() 中公开会在停机期间抛错，其后的清理语句不再执行：需要保留最终快照的模块把公开动作放在 start() 或运行期
