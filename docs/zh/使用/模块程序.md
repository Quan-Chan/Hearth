# 模块程序与上下文方法

## 程序文件写法

程序文件支持三种写法，最终归一化为同一个对象：

```js
// CJS 直接导出对象
module.exports = {
  start(ctx) {},
  stop(ctx) {},
  onEvent(ctx, event) {},
  onMessage(ctx, message) {},
};
```

```js
// ESM 默认导出
export default {
  start(ctx) {},
  onEvent(ctx, event) {},
};
```

```js
// 返回对象的工厂函数（每次启动重载时重新求值）
module.exports = function () {
  return { start(ctx) {} };
};
```

模块名不写在程序里，唯一来源是 YAML 的 name。每次启动模块时核心从磁盘重新加载程序文件。

## 四个钩子

| 钩子 | 调用时机 | 说明 |
| --- | --- | --- |
| start(ctx) | 模块被启动时调用一次 | 做初始化、公开对象、订阅资源 |
| stop(ctx) | 模块被停止时调用 | 返回即已关闭，异步收尾必须在返回前完成；未实现则立即视为已关闭 |
| onEvent(ctx, event) | 模块收到事件时调用 | 未实现则收不到事件 |
| onMessage(ctx, message) | 模块收到定向信息时调用 | 未实现则收不到定向信息 |

钩子全部可选。单个钩子抛错只记日志，不影响其他模块。

## 上下文方法

ctx 是核心提供给模块的操作入口。

| 成员 | 说明 |
| --- | --- |
| moduleName | 模块名 |
| config | 当前配置（含 YAML 全部字段），热更新后自动刷新 |
| sendEvent(name, data?) | 产生一个事件，来源段自动为模块名 |
| sendTo(target, data?) | 定向发送信息，返回是否送达 |
| exposeObject(name, value?) | 公开对象，name 为第三段，前两段自动拼装 |
| object(pattern) | 匹配拉取：不含通配符返回该对象引用；含通配符返回 { 对象全名: 引用 } 映射 |
| unexposeObject(name) | 取消公开自己的对象 |
| requestReload() | 验证新代码并重启自身，返回重启后是否处于运行态；验证失败旧实例继续运行 |
| log(...parts) | 写模块日志，类型为 module-log |

## 对象名短名规则

模块内 object(pattern) 的写法：

- 写完整名（public:模块名:对象名）：直接拉取
- 写第三段短名：自动按本模块名补齐前两段（拉自己的对象）
- 含通配符：按完整名匹配，返回映射

拉取其他模块的对象必须用完整名或通配模式。
