# 验证方法

## 测试结构

- tests/unit：部件测试（事件匹配、比对索引、配置解析、模块加载、对象注册表、日志格式、日志存储）
- tests/integration：行为测试（配置监听、定向信息、公共对象、CLI 指令、重启、停机、生命周期、同名拒绝）
- tests/apps：应用形态端到端（聊天机器人、任务调度、智能家居、监控告警）
- tests/fixtures：应用夹具模块

运行：

```bash
npm test
npm run test:unit
npm run test:integration
npm run test:apps
```

## 文档检查

npm run docs:check 执行两项检查：

- 事实对照：断言每条事实在归属文档与源码两侧都存在对应内容
- 跨文档查重：跨文档出现相同句子的段落报警

事实清单与源码位置见 scripts/verify-docs.mjs 的 FACTS 表。

## 场景映射

行为场景（冷启动、事件链、动态转发、请求重启、停机、对象共享、失败隔离、CLI 协议）以测试为锚点，见 tests 目录与 docs/zh/实现/已知问题.md 的引用。
