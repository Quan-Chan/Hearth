# 公共数组

## 注册表

ArrayRegistry 是完整名到公开项的 Map：

```ts
interface PublicArray {
  name: string;    // 完整名 public:模块名:数组名
  owner: string;   // 拥有者模块名
  items: unknown[]; // 被映射的数组对象（存引用不拷贝）
}
```

## 三段式拼装

完整名 = public:模块名:数组名。expose 与 unexpose 时调用方提供第三段与拥有者，注册表拼出完整名。不同拥有者的同名第三段不冲突。

## 匹配拉取

get(pattern) 的两种形态：

- 模式不含通配符：按完整名精确返回数组引用，不存在抛错
- 模式含通配符：遍历完整名匹配（复用事件匹配规则），返回 { 完整名: 引用 } 映射

模块上下文的 array(pattern) 额外支持短名：不含通配符且不以 public: 开头的模式按本模块名自动补齐前两段（拉自己的数组）。

## 生命周期

- 模块停止或核心停机时 removeOwner 批量注销该拥有者的全部映射，返回被删名单
- 注销后按名字不可见，持有旧引用的代码仍可操作原数组对象
- 数组无容量限制、无持久化
- 数组操作不记日志
