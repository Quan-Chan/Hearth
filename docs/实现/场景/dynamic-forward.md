# 场景：动态转发

模块在 onEvent 中重写自己的 YAML，listen 变化，转发表实时更新。

## 流程

1. 模块在 onEvent 里重写自己的 YAML，listen 增加条目。
2. ConfigWatcher 下一轮轮询：stat 指纹变化，读取内容，sha1 变化，解析，回调 onUpdate。
3. 核心更新该模块的配置引用（refreshConfig）并重建索引，记 config-update 日志。
4. 模块实例与代码不动。
5. 新 listen 即刻生效：新事件按新转发表送达。

## 边界

- 感知窗口最长一个轮询间隔，窗口内按旧转发表路由，事件丢弃且不补投。
- listen 非法值（非纯字符串）静默置空，模块从此收不到事件，无报错。
- YAML 语法错误：本轮不生效，每轮刷 error（见 已知问题 15）。
- 配置更新不重启，模块内部闭包拷贝的旧配置视图不更新。
- 每次内容不同则每轮全量解析与索引重建。
- 停机窗口内写入不生效。
- 写后立即断言读到旧值（轮询时延）。
- 一次坏读取或覆写半文件会被当作删除处理（见 已知问题 15、16）。
